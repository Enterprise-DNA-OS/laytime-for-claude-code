# Customise

Read CLAUDE.md, docs/compliance.md and the current schema. Get the operator's concrete field, workflow or report requirement. Write a new numbered migration, update the CLI and command recipe, then run npm test against disposable data. Apply with npm run migrate only to the operator's intended database. Keep old evidence and calculation revisions. Never broaden a charter interpretation or automated claim action without a separately reviewed implementation. Update brand.json for the business name, colours and logo. Show the result in chat.
